# Star Scoop (Game01 v0.2.1)

俯视飞船：收集能量晶体、躲开小行星，移动时自动射击。关卡 1–10 限时收集，11 关起无尽生存。

## Play online (GitHub Pages)

Public play: [https://peterlei853.github.io/GorkBot-Game/](https://peterlei853.github.io/GorkBot-Game/)

Pages serves the **main** branch from the repository root (`index.html`). This tree is static: relative CSS/JS, no bundler, no ES modules, so the same files work as a GitHub Pages site and as a double-clicked `index.html`.

## 怎么玩

Open the Pages URL above, or double-click **`index.html`** (no install).

或：

```bash
npm start
```

打开 http://localhost:5173

```bash
npm test
```

## 操作

| 输入 | 作用 |
|------|------|
| WASD / 方向键 | 桌面移动，可独立通关 |
| 左下虚拟摇杆 | 触屏 / iPad 移动（`touchstart` / `move` / `end`），可独立通关。摇杆只在触屏设备或发生触摸时出现 |
| 鼠标拖拽 | 可选辅助，不是通关条件 |
| 移动 | 每 **0.35s** 自动发射普通弹（没有开火键）。充能期间不发射普通弹 |
| 速度 &lt; 12 px/s | 原地充能，最多 **3.0s**。再次移动时放出能量光束，然后充能归零 |
| Esc / P 或「暂停」 | 暂停 |
| 「静音」 | 开关轻快 BGM 与音效 |

## 规则（Design Spec v0.2.1）

- 3 条命。撞上小行星 **−1** 命，沿远离小行星中心的方向弹开（冲量约 **220 px/s**），之后每帧速度 **×0.90**，直到重新可控
- **没有无敌帧**。同一次接触最多扣 1 命；中心距离大于两半径之和 **+ 2px** 才算分开，分开后再次重叠才能再扣命
- 生命为 0：Game Over，并显示本局达到的最高关卡。无在线排行榜
- 普通弹伤害 **1**，小行星生命 **1**（一发摧毁）
- 摧毁小行星有 **5%** 概率掉落发光能量，拾取后同时射击数 **1 → 2 → 3**（并排略微错开）
- 光束宽度约 **3 倍船体**，伤害 **5**，穿透路径上的多颗小行星

### 关卡 1–10

| 关卡 | 晶体 | 时间(s) | 小行星 | 速度倍率 |
|-----:|-----:|--------:|-------:|---------:|
| 1 | 8 | 70 | 4 | 1.00 |
| 2 | 10 | 68 | 5 | 1.05 |
| 3 | 12 | 65 | 6 | 1.10 |
| 4 | 14 | 63 | 7 | 1.15 |
| 5 | 16 | 60 | 8 | 1.20 |
| 6 | 18 | 58 | 9 | 1.25 |
| 7 | 20 | 55 | 10 | 1.30 |
| 8 | 22 | 53 | 11 | 1.35 |
| 9 | 24 | 50 | 12 | 1.40 |
| 10 | 26 | 48 | 13 | 1.45 |

收满目标即过关（`currentLevel` 从 1 起，过关 +1）。超时失败。速度倍率 `1 + (level − 1) × 0.05`。

### 关卡 11+（无尽）

- 没有收集过关目标。HUD 显示关卡和生存时间，不显示收集进度
- 小行星数量 `round(2.5 + level × 1.5)`，速度倍率继续用上面的公式
- 生存满一波后关卡 +1，危险按新公式刷新。波次时长沿用 1–10 关的时间数列（70, 68, 65, 63, …），低于 15 秒时保持 15 秒。到时不会失败
- 只有生命归零才结束，并显示最高关卡
